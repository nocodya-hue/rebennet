# Limpiezas Rebennet · propuesta de web

Propuesta de rediseño de [rebennet.es](https://rebennet.es), empresa de limpieza en Algemesí (Valencia): Inicio, Servicios y Contacto con los textos de su web actual.

**Ver la web:** https://nocodya-hue.github.io/rebennet/

- HTML, CSS y JavaScript estáticos (GSAP + Lenis para el movimiento), tipografía Inter autoalojada.
- Las páginas se generan con `node tools/build.mjs` (cabecera y pie compartidos).
- El formulario está en modo de vista previa: no envía nada hasta configurar `FORM_ENDPOINT` en `js/main.js`.

> Web de muestra. Las fotografías son imágenes generadas con IA, provisionales hasta contar con fotos reales del equipo.
